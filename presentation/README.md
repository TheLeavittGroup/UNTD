# The Leavitt Group Presentation

A customizable in-home solar presentation tool for sales reps.

Live page:

https://theleavittgroup.github.io/UNTD/presentation/

## What it does now

- Rep and company customization from the settings panel
- Company logo upload
- Rep photo upload
- Rep bio and proof-link support
- Local browser save using `localStorage`
- Export/import settings as JSON
- Full-screen presentation mode
- Homeowner discovery board
- Pain-point checklist
- Live solar-vs-utility savings calculator
- Canvas chart comparing utility path and solar path
- Closing script builder
- Copyable full deal summary
- Objection-handling section
- Install timeline section
- Print snapshot support

## Sales flow

1. Frame the appointment
2. Discover the homeowner's pain
3. Capture the goal and exact language
4. Show the current utility path
5. Compare the solar path
6. Present the design and protection stack
7. Prove the rep/company/process
8. Handle objections and close next step

## Notes

The current version stores custom settings locally in the user's browser. It does not upload customer data or images to a backend. For a team-wide SaaS-style tool, the next major upgrade should be a real backend for account login, saved rep profiles, company templates, saved presentations, and admin-controlled branding.
